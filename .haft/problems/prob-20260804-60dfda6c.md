# Implement S02 — Inspect one valid plain essay

## Signal

S01 landed the plugin-readable blocked-inspection path but only ever reports metadata_blocked. Milestone A's next increment requires inspect-publication to report real state for a valid blog/essay: publication identity plus independent absent candidate/approved/reference/release states. Malformed identity or a missing source ID must still report metadata_blocked. G1/G2 are decided and S01 is merged, unblocking this.

## Constraints

- Requirements introduced: ADM-02, ADM-03 (essay only), ADM-04 (essay only), SEM-01 (current source only), RVA-01 (absent state), BRG-04 — no other requirement is pulled in.
- Acceptance boundary is one in-memory vault note plus the CLI response; add real vault-reading/path-confinement behaviour behind the behaviour-proven API only after the in-memory acceptance test is green.
- Explicitly excluded: whole-vault discovery, other publication kinds, links, assets, candidates, translation, and review files.
- At most one new production boundary adapter beyond what S01 already introduced.
- In-memory/in-process acceptance subset stays under 1 second.
- Testing discipline: nullables over mocking for I/O-touching collaborators; SBPP (Smalltalk Best Practice Patterns, Java 17+ adaptation) and Riel's OO design heuristics govern every class introduced, matching S01 precedent.
- Follows the outside-in TDD loop from openspec/implementation-plan.md: failing acceptance test first, smallest inline behaviour, extract adapter only after green.
- Reuses S01's BridgeResponse/Diagnostic/VaultRelativePath/VaultReader shapes rather than introducing parallel structures unless a genuine new invariant forces a change.

## Optimization Targets

- One coherent, independently reviewable commit implementing exactly ADM-02/03/04(essay)/SEM-01(current source)/RVA-01(absent)/BRG-04's inspect-only slice
- Plugin contract harness (schema-v2) accepts the emitted response for both the valid-essay and malformed-identity cases

## Observation Indicators

- Lines of code added (watch, do not optimize for fewer)
- Number of classes introduced (watch for premature abstraction, do not optimize away legitimate ones)

## Acceptance

An OpenSpec change for S02 is approved and implemented: a failing GIVEN-WHEN-THEN acceptance test at the CLI boundary goes green for (a) a valid blog/essay reporting identity plus independent absent candidate/approved/reference/release states, and (b) malformed identity or missing source ID reporting metadata_blocked; both responses validate against bridge-contract/schema-v2.json, and the whole change lands as one reviewable commit with the prior S01 acceptance suite still green.

## Blast Radius

publication-exporter/ (new inspect/admission/identity code plus a real vault-reading adapter behind the proven API); no changes to exporter-java, obsidian-plugin runtime behaviour, site, or review-workspace.

## Reversibility

high
