# Implement S01 — plugin-readable blocked inspection

## Signal

Milestone A cannot start until one real, plugin-consumable exporter behaviour exists. S01 is the first slice: invoking inspect-publication --json for an unsafe or absent note must produce exactly one plugin-accepted schema-v2 blocked response with a non-zero exit code. G1 and G2 are now decided, unblocking this.

## Constraints

- Requirements introduced: BRG-01 (inspect only), BRG-02, BRG-03 — no other requirement is pulled in.
- The real CLI adapter calls the smallest application entry point; the plugin contract harness consumes its JSON output.
- Path input is treated as data, not shell syntax (no shell interpolation).
- Excluded: Markdown parsing, valid-note success path, review workspace, workflow states beyond metadata_blocked, and every mutating command.
- At most one new production boundary adapter (the CLI adapter itself).
- In-memory/in-process acceptance subset stays under 1 second.
- Testing discipline: nullables over mocking for I/O-touching collaborators; SBPP (Smalltalk Best Practice Patterns, Java 17+ adaptation) and Riel's OO design heuristics govern every class introduced.
- Follows the outside-in TDD loop from openspec/implementation-plan.md: failing acceptance test first, smallest inline behaviour, extract adapter only after green.

## Optimization Targets

- One coherent, independently reviewable commit implementing exactly BRG-01/02/03's inspect-only slice
- Plugin contract harness accepts the emitted schema-v2 response

## Observation Indicators

- Lines of code added (watch, do not optimize for fewer)
- Number of classes introduced (watch for premature abstraction, do not optimize away legitimate ones)

## Acceptance

An OpenSpec change for S01 is approved and implemented: a failing GIVEN-WHEN-THEN acceptance test at the CLI boundary goes green, `inspect-publication --json` on an unsafe/absent note returns one schema-v2 blocked response validated against bridge-contract/schema-v2.json with a non-zero exit code, and the whole change lands as one reviewable commit.

## Blast Radius

New publication-exporter/ Maven project (production code) and bridge-contract/schema-v2.json; no changes to exporter-java, obsidian-plugin runtime behaviour, site, vault, or review-workspace.
