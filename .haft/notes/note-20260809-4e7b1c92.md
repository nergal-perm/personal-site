# Translation review is an Obsidian-plugin handoff to one Zed workspace

## Observations

- The Java bridge prepares and reports the review plan; it does not open an editor. Opening review files is an operator-interface responsibility of the Obsidian plugin.
- The plugin now invokes Zed once with both candidate paths for a first review (`-n ru.md en.md`), or both RU and EN baseline-to-candidate pairs for a changed review (`-n --diff published/ru.md ru.md --diff published/en.md en.md`). The reviewer sees the pair in one new Zed workspace.
- The modal, settings description, notices, failure diagnostic, timeout handling, and plugin tests were changed together so the UI describes the actual one-window behavior.

## Rationale

Keeping editor launch outside the bridge preserves the bridge as a deterministic vault/review-artifact boundary and keeps machine-specific Zed behavior in the plugin. One workspace keeps the bilingual review pair together without weakening the review-plan paths supplied by the bridge.
