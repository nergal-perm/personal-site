# Operator accepts pre-publication semantic ID admission

## Observations

- Before a page may enter semantic Prepare or approval, the current page and each uniquely resolved direct semantic link target must already carry a stable source ID.
- Prepare may inspect those direct targets and block with an actionable list when an ID is missing; the human operator assigns the IDs and reruns Prepare.
- The requirement applies to private targets before they become publishable, so an approved referrer can retain the target identity and later activate without changing or reapproving the referrer.

## Rationale

A target identity assigned only when the target itself is published is too late for already-approved referrers. Human assignment is acceptable to the operator and keeps Prepare from silently mutating unrelated private notes while making identity admission explicit and reviewable.
