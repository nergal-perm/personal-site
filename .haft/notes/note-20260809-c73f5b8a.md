# Native S05-S07 pilot passed against the real review workspace and an isolated site copy

## Observations

- GraalVM native-image initially exposed Jackson serializer/reflection gaps for `ReferenceMap`, `RussianDiff`, `ReleaseResult`, `ReleaseProvenance`, and `InstallToSiteResult`. Explicit reflection metadata was added in `publication-exporter/src/main/resources/META-INF/native-image/reflect-config.json`; the JVM behavior alone had not exposed these gaps.
- The rebuilt native executable completed `build-from-review` for `blog/essay-tdd-fractality` from the real approved review snapshot. It wrote `ru.md`, `en.md`, and `release-provenance.json` under `/private/tmp/publication-m1.iJjBMO/release-native/blog/essay-tdd-fractality/release/`. The result bound matching approved and output hashes, contract edition 1, and zero activation/deactivation counts.
- The same native executable refused `install-to-site` with no approved snapshot before creating the requested temporary site root, then successfully installed the approved essay into the disposable `site-full-first` copy.
- `npm --prefix /private/tmp/publication-m1.iJjBMO/site-full-first run build` passed the site's content validation and built 73 Astro pages. The generated temporary distribution contained both `/ru/essays/essay-tdd-fractality/` and `/en/essays/essay-tdd-fractality/`.
- After the status and native-response fixes, `mvn -f publication-exporter/pom.xml test` passed with 462 tests, 0 failures, and 0 errors. Focused build-from-review/install-to-site CLI acceptance tests also passed (8 tests).
- This was a disposable integration exercise only: no production site tree was installed or deployed, and the temporary fixture roots remain for inspection.

## Rationale

The real-vault and isolated-real-site path supplies the missing integration evidence that unit suites and JVM-only runs cannot provide: the native executable can cross the bridge's file contracts, read an approved bilingual snapshot, materialize it, install it into the managed site layout, and satisfy Astro's own build gate. Retaining the temporary artefacts keeps that evidence inspectable without treating the pilot as a production release.
