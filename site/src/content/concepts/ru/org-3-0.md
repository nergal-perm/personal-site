## Определение

**Организация 3.0** — концепция агентоцентричной компании, в которой стратегические решения автоматически транслируются в цели, а цели становятся промптами для AI-агентов, которые формируют операционный план.


## Эволюция организаций

| Версия | Управление | Координация |
|--------|-----------|-------------|
| Org 1.0 | Иерархия + приказы | Личная коммуникация |
| Org 2.0 | Иерархия + SaaS-системы (CRM, ERP) | Электронные системы трекинга |
| Org 3.0 | Решения → Цели → Агенты | AI-агенты как операционный слой |

Традиционные организации спроектированы вокруг **ограничений человеческой коммуникации**. Генерал не может отдать прямой приказ каждому из сотен тысяч солдат — поэтому нужна иерархия. AI-агенты снимают это ограничение.

## Ключевой сдвиг

Сегодня: Стратегия → Менеджеры → Задачи → Сотрудники (5–7 уровней, огромные потери на передачу информации)

Org 3.0: Стратегия → Цели → Промпты → Агенты → Результат (минимальное трение)

## Текущее состояние

По состоянию на 2026-05: концепция в стадии эксперимента. Примеры частичной реализации:
- Venture-фонды с агентскими системами для поиска и анализа фаундеров
- Shopify, Block — AI-first процессы, включая требование AI-обоснования перед наймом

## Конкретизация через Block

Статья From Hierarchy to Intelligence делает Org 3.0 более операциональной. Block описывает не просто агентов вместо менеджеров, а четыре слоя компании:

1. **Capabilities** - атомарные финансовые строительные блоки.
2. **World model** - модель компании и клиентов.
3. **Intelligence layer** - слой композиции возможностей в решения.
4. **Interfaces** - продукты и устройства как поверхности доставки.

Ключевое уточнение: AI-native организация требует наличия модели мира компании, иначе агенты остаются оптимизацией существующей иерархии, а не заменой ее информационной функции.

## Предпосылки для внедрения

1. Персональная AI-ОС у каждого лидера
2. Командная AI-ОС как общая инфраструктура
3. Только затем — корпоративный уровень

## Связанные концепты

- AI-театр — что происходит без этой архитектуры
- Пространство решений агента — как ограничивать автономию агентов
- Компания как интеллект — близкая формулировка
- Модель мира компании — инфраструктура координации без менеджерской цепочки
